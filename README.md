# LIBRARY｜私人藏書室 v2

## 使用方式
1. 解壓縮資料夾。
2. 用瀏覽器開啟 `index.html` 即可測試。
3. 測試密碼預設為 `change-this-password`，可在 `js/app.js` 最上方修改。

## v1
- 首頁與作品統計
- 前端密碼門（原型）
- 明暗主題切換
- 作品新增與編輯
- 多標籤與標籤篩選
- 搜尋與排序
- 封面卡片／清單切換
- LocalStorage 暫存資料

## v2 新增
- 一部作品可新增多個章節。
- 章節可編輯、刪除、調整順序。
- 章節可設定為草稿或已發布。
- 閱讀器：章節目錄、上一章／下一章、字體大小、紙張／暖色／夜間背景。
- 自動記錄每部作品上次閱讀的章節與閱讀進度。
- 作品字數改為統計所有章節內容。
- 舊版 `body` 正文會在載入時轉成「第一章」，盡量保留舊資料。

## 儲存與重要提醒
目前仍使用瀏覽器 LocalStorage，資料只存在目前瀏覽器／裝置中。請定期備份瀏覽器資料；清除網站資料可能造成作品遺失。
目前密碼是前端原型入口，不是安全驗證。正式公開使用前，需改接 Supabase Auth 與資料庫權限控管。
