# LIBRARY｜私人藏書室（前端原型）

## 本機預覽
直接用瀏覽器開啟 `index.html`，或使用 VS Code Live Server。

## 暫時密碼
開啟 `js/app.js`，修改最上方的 `SITE_PASSWORD`。

**安全提醒：** 目前密碼檢查只在瀏覽器端執行，任何能讀取網站原始碼的人都可能繞過。不要用它保護真正機密的內容。正式部署前應改用 Supabase Auth + RLS，並把作品資料存入 Supabase。

## 目前功能
- 首頁與作品統計
- 前端密碼門（原型）
- 明暗主題切換
- 作品新增與編輯
- 多標籤與標籤篩選
- 搜尋與排序
- 封面卡片／清單切換
- LocalStorage 暫存資料

## 下一階段
